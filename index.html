How it is built

Four pages share one stylesheet and one navigation. The navigation is not copied into each page: it lives in nav.html and nav.js fetches it and marks the current page, so a new link means editing one file instead of four.

Everything is plain HTML, CSS and JavaScript — no framework, no build step. The layout is mobile-first: the styles describe the phone, and wider screens get extra columns. If a script fails, the content is still there to read, which is the point of writing the structure first and the decoration second.
