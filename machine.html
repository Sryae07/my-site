The machine

A useless machine does exactly one thing: when you turn it on, it turns itself off. The pleasure is in watching something refuse to be useful.

Useless machine

Try it

Click the switch. A hand arrives, pushes it back down, and leaves. That is the whole machine.

The machine is off. It is waiting.

It is built from one button, one CSS transition and a short animation: no images, no canvas. The state is announced with aria-pressed, so a screen reader knows whether the machine is on before the hand gets there.

Catch the dot

Thirty seconds. A dot appears somewhere in the box; click it and it moves. Keyboard works too — the dot is a button, so Tab to it and press Enter.
